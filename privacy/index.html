Privacy Policy for German Highlight Translator

Last updated: September 7, 2026

German Highlight Translator is a Chrome extension that translates text a user explicitly highlights on a webpage from German to English and displays the translation near the selected text.

Information the Extension Processes

The extension processes only the text that you deliberately highlight for translation. It does not require you to create an account or provide personal information.

How Translation Works

Translation is performed using Chrome's built-in Translator API. The extension does not send highlighted text to a translation server operated by the developer and does not use an external translation API. Chrome may download and manage language resources required by its built-in translation feature as part of the browser.

Data Collection

The developer does not collect, store, or retain:

  • Highlighted or translated text
  • Browsing history
  • Website URLs
  • Names, email addresses, or other personal information
  • Authentication information
  • Location information
  • Analytics or advertising identifiers

Data Sharing and Sale

The extension does not sell, rent, share, or transfer user data to advertisers, data brokers, or other third parties. Highlighted text is not used for advertising, profiling, or any purpose unrelated to providing the requested translation.

Website Access

The extension runs on webpages so it can detect text that the user selects and display the translation popup next to that selection. This access is used only to provide the extension's German-to-English translation feature. The extension does not store webpage content or browsing activity.

Data Retention

The developer does not retain user data. Selected text is used only for the immediate translation request and is not saved by the extension after that interaction.

Security

Because the extension does not send selected text to or store it on developer-controlled servers, the developer does not maintain a remote database of users' highlighted or translated text.

Changes to This Privacy Policy

This policy may be updated if the extension's features or data practices change. Any revised policy will be posted on this page with an updated revision date.

Contact

Questions about this privacy policy or the extension can be submitted through the German Highlight Translator GitHub repository: https://github.com/baileyfcross/german-highlight-translator
